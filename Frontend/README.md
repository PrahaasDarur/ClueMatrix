# ClueMatrix Frontend

## Run locally

Install Node.js 20.19+ (or 22.12+) and then run these commands from this folder:

```powershell
npm ci
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Production build

```powershell
npm run build
npm run preview
```

The current interface uses demonstration data; it does not yet connect to the
backend API.
